# Contributing

Each repository documents its own development workflow and support status.
Please read that repository's README and CONTRIBUTING file before opening a
pull request.

New projects should meet the criteria in the organization
[repository lifecycle policy](REPOSITORY_LIFECYCLE.md) before a standalone
repository is created.

For changes to the core application, use
[`neonwatty/meme-search`](https://github.com/neonwatty/meme-search) until its
planned organization transfer is complete.
