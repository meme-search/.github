# Security

Do not open a public issue for a suspected vulnerability.

For the core application or an integration that depends on it, follow the
[Meme Search security policy](https://github.com/neonwatty/meme-search/security/policy).
Include the affected repository and version, deployment details, reproduction
steps, likely impact, and suggested mitigation. Remove API keys, private images,
database contents, and personal filesystem paths.
